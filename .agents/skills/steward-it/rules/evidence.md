# Evidence Recording

## When this applies

Load only when the consuming project maintains a stewardship evidence file and the current review produces
an observation durable enough to retain.

## Convention

Record a compact observation, normally no more than two sentences, with a concrete issue, commit, PR,
or other reference when one exists.

Do not create a diary, copy the retrospective, or restore a retired evidence file merely because no current
file exists. A missing evidence store is a project-state fact, not a reason for steward-it to invent one.

Evidence should preserve the reusable observation, not the full session narrative. Later stewardship may use
retained entries to distinguish a one-off from a recurring pattern.
